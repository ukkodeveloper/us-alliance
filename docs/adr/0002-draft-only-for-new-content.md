# 0002. 임시저장은 신규 작성에만

- 상태: 채택
- 출처: AI 제안 → 수용

## 맥락

요구사항은 "임시저장은 1개의 콘텐츠만"이고, 이어쓰기 진입점은 새글쓰기 모달뿐입니다. 시안에는 수정 화면 헤더에도 임시저장 버튼이 있습니다.

## 대안

- A. 신규 작성만 저장하고, 수정 화면에서는 임시저장 버튼을 숨긴다
- B. 수정도 저장하고, 콘텐츠 id를 함께 저장해 이어쓰기 때 PUT으로 보낸다

## 결정

A. 수정은 서버에 원본이 있고, 이어쓰기 진입점이 새글쓰기 모달 하나뿐이라 수정 중인 글을 다시 꺼낼 경로가 없습니다.

## 결과

- 수정 중에 화면을 떠나면 고친 내용이 사라집니다. README "하지 않은 것"에 적었습니다.
- 시안의 수정 화면 헤더와 다릅니다.
- 콘텐츠 생성에 성공하면 임시저장을 지웁니다. 발행 모달이 열린 동안에는 자동저장을 멈춥니다(리뷰에서 발견해 수정, `f900623`).
- 관련 커밋: `e49b91d`, `bcf7ed1`
