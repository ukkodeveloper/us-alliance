# 0007. 예약 시간 선택은 react-datepicker

- 상태: 채택
- 출처: AI 제안 → 수용

## 맥락

캘린더와 분 단위 시간 선택이 필요하고, 지난 시각은 고를 수 없어야 하며, "yyyy년 MM월 dd일 HH시 mm분"으로 표시해야 합니다.

## 대안

- A. react-datepicker + date-fns
- B. 네이티브 `datetime-local` (표시 형식을 바꿀 수 없음)
- C. 직접 구현

## 결정

A. 시안의 캘린더와 시간 열 UI와 모양이 같고, 설정만으로 요구를 채웁니다. date-fns는 목록 날짜 포맷에도 다시 씁니다.

## 결과

- 의존성이 2개 늘었습니다.
- 시간 간격은 10분으로 가정했습니다.
- 서버에는 `+09:00`이 붙은 ISO 문자열로 보냅니다(`toKstIsoString`, 테스트 있음).
- 모달 안에서 달력이 열린 상태로 ESC를 누르면 모달까지 닫히는 문제를 발견해 고쳤습니다(`e2a19f6`).
- 관련 커밋: `0dc75ed`, `97042d2`
